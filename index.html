Hinweise und Datenschutz

Die Seite ruft ausschließlich die öffentliche Read-only-API von Sleeper auf. Es werden keine Zugangsdaten benötigt oder gespeichert. Draft-Link, Slot und Spieler-Datenbank-Zeitpunkt werden nur lokal im Browser gespeichert.

Falls „Netzwerkfehler/CORS“ erscheint, öffne die Datei nicht direkt als file://, sondern hoste sie über GitHub Pages, Netlify oder Cloudflare Pages. Die Spieler-Datenbank ist groß und wird nur einmal pro Tag geladen.
