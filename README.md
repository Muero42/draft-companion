# Sleeper Draft Companion Mobile v1.3

Für Android optimierte PWA.

## Wichtigste Bedienung

1. Sleeper-Link einfügen.
2. Eigenen Slot wählen.
3. Ab dann pro Pick nur noch **„Aktualisieren & kopieren“** drücken.
4. In ChatGPT einfügen.

Alternativ kann über **„Teilen“** direkt das Android-Teilen-Menü geöffnet werden.

## Mobile Verbesserungen

- große, unten fixierte Aktionsbuttons
- Aktualisieren und Kopieren in einem Schritt
- Android Share Sheet
- automatische Wiederverbindung beim Öffnen
- Link, Slot und Einstellungen bleiben lokal gespeichert
- manuelle Spielerliste nur noch als Notfalloption
- als PWA zum Startbildschirm installierbar

## Veröffentlichung

Den gesamten entpackten Ordner bei Netlify Drop, GitHub Pages oder Cloudflare Pages hochladen.
Danach die URL auf Android öffnen und „Zum Startbildschirm hinzufügen“ wählen.
